# Changelog

## 0.1.0 (2026-09-26)

First public release of Daybow.

- Chrome extension: labels every event on your primary calendar with one of nine categories chosen by Jev.
- Instant color: predicts the category while you type the title and paints the new chip in the same frame that it appears.
- Categories editor that looks like Google Calendar. Each category appears as events made from its example titles. Click one to pick from 24 preset pastel colors or a custom color, rename it, describe it, or edit its example titles. Click an empty spot in a day to add a category.
- Edits made to labels in Google Calendar are adopted.
- In-place repaint on the Calendar page, with a wave for batch changes and past-event tints.
- Optional web app on Vercel: server-side labeling through Google push notifications, a daily sweep, and a status page.
- Demo video made in code with Remotion.
